# SmsSense

一個將 Android 手機上的簡訊、白名單 App 通知，以及全畫面登入確認彈窗單向轉發到 Telegram 的輕量工具。

平常雙手機或出門帶平板時，驗證碼簡訊或 Google／銀行的登入確認視窗常跳在另一台裝置上。`SmsSense` 會以原文完整轉發收到的簡訊，遇到驗證碼時在最上方額外附上一行可點擊複製的數字；App 通知與登入彈窗則採嚴格白名單制，只轉發你勾選的 App，不洗版、也不含任何遠端模擬點擊功能。

## 主要功能

- **簡訊全文轉發**：完整合併長簡訊並以原文轉發到 Telegram，同時提供可選的「驗證碼置頂」，方便單擊複製且不怕截錯。
- **來電響鈴轉發**：備用機來電響鈴時即時推播發話號碼，不怕漏接重要來電。
- **低電量守護警報**：電量低於設定門檻（預設 20%）時發送警報，插上充電或充回門檻 + 10% 自動重置防洗版。
- **自動標記裝置型號／別名**：自動帶入裝置型號（如 `SM-N960F`、`小米14T`）或自訂別名，多台備用機推播一目了然。
- **白名單 App 通知與全畫面通知**：只監聽你主動勾選的 App（可直接從已安裝清單搜尋勾選），遇到帶 `fullScreenIntent` 或含確認按鈕的通知會特別標註。
- **全畫面登入彈窗感知（唯讀）**：針對不經過通知欄、直接跳出前景的登入確認視窗（例如 Google 提示、Microsoft Authenticator、銀行 App 確認窗），以唯讀無障礙權限偵測視窗彈出並發送 Telegram 提醒。
- **去重與斷網補發**：5 秒內自動濾掉簡訊與簡訊 App 通知重複觸發；無網路時先存本機佇列，透過 WorkManager 在恢復連線後自動補送。

## 權限說明

所有資料只會直接送到你自己設定的 Telegram Bot，不經過任何第三方中繼伺服器。

- **簡訊權限（`RECEIVE_SMS`）**：攔截實體簡訊。
- **電話與通話紀錄權限（`READ_PHONE_STATE`、`READ_CALL_LOG`）**：擷取來電響鈴與發話號碼。
- **通知存取權限（Notification Access）**：讀取白名單 App 的通知與全畫面通知。
- **無障礙服務（唯讀視窗偵測，選配）**：僅用於偵測白名單 App 跳出前景登入彈窗時發出提醒；不具備點擊或輸入操作權限。若遇 Android 14 以上系統遮蔽文字的敏感畫面，仍會發送「該 App 已彈出確認視窗」的提醒。
